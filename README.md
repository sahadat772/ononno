## 📖 পরিচিতি

**অনন্য** একটি সম্পূর্ণ বাংলা ভাষায় তৈরি AI-powered শিক্ষা প্ল্যাটফর্ম যা বাংলাদেশের শিক্ষার্থীদের জন্য বিশেষভাবে ডিজাইন করা হয়েছে। এটি একাডেমিক শিক্ষা, ইসলামিক শিক্ষা এবং শিশুদের প্রাথমিক শিক্ষাকে একটি আধুনিক ডিজিটাল প্ল্যাটফর্মে একত্রিত করেছে।

আমরা বিশ্বাস করি **শিক্ষা সবার অধিকার** — তাই এতিম, দরিদ্র ও প্রতিবন্ধী শিক্ষার্থীদের জন্য সম্পূর্ণ বিনামূল্যে অ্যাক্সেসের ব্যবস্থা রয়েছে।

## ✨ মূল বৈশিষ্ট্য

### 🎓 একাডেমিক শিক্ষা
- Nursery থেকে বিশ্ববিদ্যালয় পর্যন্ত সম্পূর্ণ NCTB curriculum
- AI-powered lesson content generation
- Interactive quiz ও assessment
- Real-time progress tracking

### 🕌 ইসলামিক শিক্ষা
- কুরআন তাফসীর ও তাজউইদ
- হাদিস ব্যাখ্যা
- দুআ সংগ্রহ
- ফিকহ ও সিরাহ
- সাপ্তাহিক ইসলামিক বিশ্লেষণ

### 👶 Kids Zone (শিশু বিভাগ)
- বাংলা বর্ণমালা — ইন্টারেক্টিভ lesson engine
- ইংরেজি ABC — voice-based learning
- আরবি হরফ — pronunciation check
- গণিত — gamified approach
- ১১ ধরনের interactive exercise

### 🤖 AI Features
- **AI Tutor** — Groq LLaMA 3.3-70B দিয়ে ব্যক্তিগতকৃত সহায়তা
- **Weakness Detection** — দুর্বল বিষয় চিহ্নিত করে উন্নতির পরামর্শ
- **Learning Path** — AI-generated দৈনিক পাঠ পরিকল্পনা
- **Performance Prediction** — ভবিষ্যৎ পারফরম্যান্স পূর্বাভাস
- **Pronunciation Check** — Groq Whisper দিয়ে উচ্চারণ যাচাই
- **Career Guidance** — AI-based ক্যারিয়ার পরামর্শ

### 💳 Payment System
- **bKash** — Tokenized API integration
- **Nagad** — Manual flow
- **SSLCommerz** — Card payment
- **Manual Payment** — bKash/Nagad Send Money + Admin approval
- Class-based subscription plans (৳৯৯ থেকে শুরু)

### 🔔 Notification System
- Firebase FCM Push Notification
- Subscription expire reminder (৩ দিন আগে, প্রতি ১২ ঘণ্টা)
- Student login/logout alert (Parent/Teacher কে)
- Payment success notification

## 🗄️ Database Tables

```
profiles              — User profiles (student, parent, teacher, admin)
subscriptions         — Active subscriptions
payment_transactions  — Payment history
notifications         — In-app & push notifications
learning_progress     — Lesson completion tracking
student_stats         — XP, streak, total lessons
ml_training_data      — AI/ML training data per student
ml_student_analysis   — Weakness analysis results
fcm_tokens            — Firebase push notification tokens
free_access_requests  — বিনামূল্যে অ্যাক্সেসের আবেদন
user_sessions         — Login/logout session tracking
parent_children       — Parent-child relationships
teacher_students      — Teacher-student relationships
```

## 🚀 Installation

### Prerequisites
- Node.js 18+
- npm বা yarn
- Supabase account
- Groq API key
- Firebase project

### Setup

```bash
# Repository clone করো
git clone https://github.com/your-username/ononno.git
cd ononno

# Dependencies install করো
npm install

# Environment variables setup করো
cp .env.example .env.local
```

### Environment Variables

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

# Groq AI
GROQ_API_KEY=

# bKash
BKASH_APP_KEY=
BKASH_APP_SECRET=
BKASH_USERNAME=
BKASH_PASSWORD=
BKASH_BASE_URL=https://tokenized.sandbox.bka.sh/v1.2.0-beta

# SSLCommerz
SSLCOMMERZ_STORE_ID=
SSLCOMMERZ_STORE_PASSWORD=
SSLCOMMERZ_IS_LIVE=false

# Firebase Client
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
NEXT_PUBLIC_FIREBASE_VAPID_KEY=

# Firebase Admin (Server only)
FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=

# App URL
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### Run করো

```bash
# Development
npm run dev

# Production build
npm run build
npm start
```

## 🔐 Access Control

```
Free User
├── প্রতিদিন ১টা lesson
├── Ads দেখবে
└── Limited content

Subscribed User (নির্দিষ্ট class)
├── সেই class এর সব content
├── অন্য class দেখা যাবে (locked)
├── No Ads
└── AI Tutor unlimited

Family Plan
├── সব class এর content
├── ৫ জন student
└── Parent dashboard

Free Access (Admin approved)
├── সব content বিনামূল্যে
├── ১ বছরের জন্য active
└── এতিম/দরিদ্র/প্রতিবন্ধী শিক্ষার্থী
```
