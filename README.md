# 🌿 অনন্য — Ononno Education Platform

### শিক্ষার প্রতিটি ধাপে, অনন্য সঙ্গী

বাংলাদেশের প্রথম AI-powered ইসলামিক শিক্ষা প্ল্যাটফর্ম

## 📖 পরিচিতি

অনন্য একটি সম্পূর্ণ বাংলা ভাষায় তৈরি AI-powered শিক্ষা প্ল্যাটফর্ম যা বাংলাদেশের শিক্ষার্থীদের জন্য বিশেষভাবে ডিজাইন করা হয়েছে। এটি একাডেমিক শিক্ষা, ইসলামিক শিক্ষা এবং শিশুদের প্রাথমিক শিক্ষাকে একটি আধুনিক ডিজিটাল প্ল্যাটফর্মে একত্রিত করেছে।

আমরা বিশ্বাস করি শিক্ষা সবার অধিকার — তাই এতিম, দরিদ্র ও প্রতিবন্ধী শিক্ষার্থীদের জন্য সম্পূর্ণ বিনামূল্যে অ্যাক্সেসের ব্যবস্থা রয়েছে।

## ✨ মূল বৈশিষ্ট্য

### 🎓 একাডেমিক শিক্ষা - Nursery থেকে বিশ্ববিদ্যালয় পর্যন্ত সম্পূর্ণ NCTB curriculum - AI-powered lesson content generation - Interactive quiz ও assessment - Real-time progress tracking

### 🕌 ইসলামিক শিক্ষা - কুরআন তাফসীর ও তাজউইদ - হাদিস ব্যাখ্যা - দুআ সংগ্রহ - ফিকহ ও সিরাহ - সাপ্তাহিক ইসলামিক বিশ্লেষণ

### 👶 Kids Zone (শিশু বিভাগ) - বাংলা বর্ণমালা — ইন্টারেক্টিভ lesson engine - ইংরেজি ABC — voice-based learning - আরবি হরফ — pronunciation check - গণিত — gamified approach - ১১ ধরনের interactive exercise

### 🤖 AI Features - AI Tutor — Groq LLaMA 3.3-70B দিয়ে ব্যক্তিগতকৃত সহায়তা - Weakness Detection — দুর্বল বিষয় চিহ্নিত করে উন্নতির পরামর্শ - Learning Path — AI-generated দৈনিক পাঠ পরিকল্পনা - Performance Prediction — ভবিষ্যৎ পারফরম্যান্স পূর্বাভাস - Pronunciation Check — Groq Whisper দিয়ে উচ্চারণ যাচাই - Career Guidance — AI-based ক্যারিয়ার পরামর্শ

### 💳 Payment System - bKash — Tokenized API integration - Nagad — Manual flow - SSLCommerz — Card payment - Manual Payment — bKash/Nagad Send Money + Admin approval - Class-based subscription plans (৳৯৯ থেকে শুরু)

### 🔔 Notification System - Firebase FCM Push Notification - Subscription expire reminder (৩ দিন আগে, প্রতি ১২ ঘণ্টা) - Student login/logout alert (Parent/Teacher কে) - Payment success notification

## 🚀 Production readiness

### CI / pre-deploy checks
- `npm ci`
- `npx tsc --noEmit --incremental false`
- `npm run lint`
- `npm run build`
- `npm audit` নিয়মিত চালান
- বড় dependency আপডেট আলাদা ব্রাঞ্চে করে validate করুন

### Monitoring & alerts
- সার্ভার ও ক্লায়েন্ট incident logging চালু রাখুন (Sentry, Datadog, LogRocket ইত্যাদি)
- নিম্নলিখিত অ্যালার্ট বাই ডিফল্ট রাখুন:
  - API 5xx ত্রুটি spike
  - auth failure / access denied spike
  - payment webhook ব্যর্থতা
  - rate limiter reject spike
- Supabase logs ও Postgres slow query logs enable করুন
- production-এ `NEXT_PUBLIC_SUPABASE_URL` থাকলেও `SUPABASE_SERVICE_ROLE_KEY` শুধু server-side এ রাখুন

### Production deploy checklist
- নিম্নলিখিত env var ঠিকভাবে সেট করুন:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - `SUPABASE_SERVICE_ROLE_KEY`
  - `GROQ_API_KEY`
  - Firebase এবং payment credentials
- HTTPS, CSP, secure cookies, HSTS, CORS allowlist নিশ্চিত করুন
- Supabase ডাটাবেস ব্যাকআপ ও restore point চালু রাখুন
- Deploy এর আগে `npm run build` চালিয়ে নিন
